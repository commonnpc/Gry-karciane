# Gry-karciane
Zbiór różnych gier karcianych stworzonych za pomocą modułu pygame
Zanim zaczniesz upewnij się, ze wszystkie pliki (oprócz plików folderu karty) znajdują się w tym samym folderu co folder karty
W CMD wpisz komendy:
pip install pip -U pip --user
pip install pygame -U pip --user
pip install pygwidgets -U pip --user

Po tym wszystkim uruchom plik gra.py i zacznij gre :)
